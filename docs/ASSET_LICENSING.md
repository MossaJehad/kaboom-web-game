# Asset Licensing & Originality

All game artwork, audio, and branding in SKYHOP are 100% original and locally generated/stored — no proprietary Flappy Bird graphics, sounds, or stock illustrations are used.

- **Pixel-Art Sprites, Scenes, Avatars, Frames & Icons (`apps/web/public/assets/**`)**: Programmatically generated original artwork created by `scripts/generate-assets.ts` for this project. Licensed under the project license (MIT).
- **Audio & Chiptune Music (`apps/web/public/assets/audio/*.wav`)**: Programmatically synthesized original PCM WAV waveforms created by `scripts/generate-assets.ts`. No third-party copyrighted audio samples.
- **Pixel Typography**: Bundled locally via `@fontsource/press-start-2p`, `@fontsource/silkscreen`, and `@fontsource/vt323` (SIL Open Font License 1.1).
- **Game Engine & Libraries**: Kaboom.js 3000.1.17 (MIT), React (MIT), Fastify (MIT), Prisma (Apache-2.0), Tailwind CSS (MIT).
